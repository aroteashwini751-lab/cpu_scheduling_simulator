Scheduling Algorithm Decision Simulator

📌 About

A CPU Scheduling Algorithm Decision Simulator that recommends a suitable scheduling algorithm based on process characteristics.

🚀 Features

- Add and manage multiple processes.
- Enter arrival time, burst time, and priority.
- Recommend a suitable CPU scheduling algorithm.
- Simulate FCFS, SJF, SRTF, Priority, and Round Robin.
- Calculate waiting time and turnaround time.
- Display scheduling results and a Gantt chart.

🛠️ Technologies Used

- HTML – Structure of the user interface
- CSS – Styling and layout
- C++ – CPU scheduling algorithms and calculations
- Python – Backend integration

▶️ How to Run

1. Install Python and a C++ compiler.
2. Install Flask using "pip install flask".
3. Open the project folder in VS Code.
4. Run the backend using "python app.py".
5. Open the local URL displayed in the terminal.

🎯 Objective

To understand CPU scheduling algorithms and help users choose an appropriate scheduling algorithm based on process requirements.
